# Spot — app downloads

**Latest build: [Spot-11.apk](https://github.com/sharmaashutoshm-coder/spot-releases/raw/main/Spot-11.apk)**

Open that link on an Android phone to download and install Spot.
Once installed, Spot updates itself: an "Update available" card appears in the app.

`latest.json` tells the app which build is newest.
